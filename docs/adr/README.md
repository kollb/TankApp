# Architecture Decision Records

> Stand: 05.10.2026 · App-Version 0.75.0

Die ADRs halten Entscheidungen aus Konzept, Arbeitsliste und Projektstand fest.
Sie führen keine Entscheidungen ohne Freigabe ein; genehmigte Ergänzungen
werden am betroffenen ADR datiert.

| ADR | Thema | Status |
|---|---|---|
| [0001](0001-BETRIEB-UND-SPEICHER.md) | Flüchtiger Cache, SSD/HDD und Sicherungen | Angenommen |
| [0002](0002-PRODUKTUMFANG.md) | LAN-Umfang und bewusst unterlassene Erweiterungen | Angenommen |
| [0003](0003-MODELL-UND-FREIGABE.md) | Modellpfad, Kalibrierung und Produktfreigabe | Angenommen |

Format für neue ADRs: Titel · Status/Datum · Kontext · Entscheidung ·
Konsequenzen · Wiederaufnahmebedingungen. Geplante, noch nicht entschiedene
Änderungen gehören in [TODO](../planung/TODO.md), nicht unter „angenommen“.
