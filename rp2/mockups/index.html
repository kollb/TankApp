🚗 TankApp GUI Vergleich

Vergleiche die richtige GUI (NAS) mit der Fallback-GUI (RP2)

🖥️

Richtige GUI

Die vollwertige Next.js/React-GUI, die auf dem NAS läuft (Port 1355). Schönes Design mit allen Funktionen.

  • ✓ Vollwertiges Design (Slate-950, Emerald-Akzente)
  • ✓ Alle Funktionen (F1/F2/F3 + Heatmaps + Top-10)
  • ✓ Live-Daten + Live-Prognosen
  • ✓ Kampagnen- und Kraftstoff-Umschalter
  • ✓ Heatmaps und Fan-Charts
  • ✓ API Explorer
  • ✓ Responsive Design (Tabs für Mobile)
  • ✓ Service Worker für Offline-Cache

Fallback GUI

Die leichtgewichtige Python-GUI, die auf dem RP2 läuft (Port 8000). Einfaches Design für 24/7 Verfügbarkeit.

  • ✓ Einfaches, funktionales Design
  • ✓ Wichtigste Funktionen (F1/F2/F3)
  • ✓ Live-Preise + gecachte Prognosen
  • ✓ Günstigste Station + Alternativen
  • ✓ Zeitfenster-Empfehlungen
  • ✓ Navigation zu Stationen
  • ✓ NAS-Status-Anzeige
  • ✗ Keine Heatmaps/Fan-Charts
